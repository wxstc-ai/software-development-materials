# 7.2.1  事件监听

# 事件监听存在浏览器兼容问题，在早期版本的IE浏览器（IE 6~IE 8）中，事件监听的语法格式如下。

element.attachEvent(type, callback);

7.2.1  事件监听

上述语法格式中，attachEvent()方法可以为对象添加事件监听，该方法中的第1个参数type表示为对象注册的事件类型，带有on前缀，如onclick；第2个参数callback表示事件处理函数。

# 在新版浏览器（如IE 9及之后的版本、Chrome、Firefox）中，事件监听的语法格式如下。

element.addEventListener(type, callback, [capture]);

7.2.1  事件监听

上述语法格式中，addEventListener()方法可以为对象添加事件监听，该方法的第1个参数type表示为对象注册的事件类型，不带on前缀；第2个参数callback表示事件处理函数；第3个参数capture是可选参数，默认值为false，表示在事件冒泡阶段完成事件处理，将其设置为true时，表示在事件捕获阶段完成事件处理。

# 7.2.1  事件监听

通过事件监听的方式添加的多个事件处理函数具有触发顺序，浏览器的类型也会影响触发顺序。

# 7.2.1  事件监听

下面以在Chrome浏览器中进行事件监听为例，演示addEventListener()方法的使用，示例代码如下。

<body>

  <script>

    // 添加第1个事件处理函数

      console.log('one');

      console.log('two');

# 熟悉DOM事件流，能够说明DOM事件流的3个阶段

7.2.3	DOM事件流

先定一个小目标！

# 7.2.3	DOM事件流

# 事件流分为事件捕获和事件冒泡。事件捕获由网景公司的团队提出，指的是事件流传播的顺序应该是从DOM树的根节点一直到发生事件的节点；事件冒泡由微软公司的团队提出，指的是事件流传播的顺序应该是从发生事件的节点到DOM树的根节点。

7.2.3	DOM事件流

# W3C对网景公司和微软公司提出的方案进行了中和处理，将DOM事件流分为3个阶段，具体如下。

事件捕获阶段：事件从document节点自上而下向目标节点传播的阶段。
事件目标阶段：事件流到达目标节点后，运行相应的事件驱动程序的阶段。
事件冒泡阶段：事件从目标节点自下而上向document节点传播的阶段。

7.2.3	DOM事件流

# 当事件发生后，浏览器首先进行事件捕获，但不会对事件进行处理，然后进入事件目标阶段，运行目标节点的事件驱动程序，最后进入事件冒泡阶段，逐级对事件进行处理。

2. 阻止元素的默认行为

在HTML中，有些元素自身拥有一些默认的行为，例如，使用<a>标签创建的链接被单击时，浏览器会自动跳转到href属性设置的URL地址；单击表单的提交按钮后，浏览器会自动将表单数据提交到指定的服务器处理。

在实际开发中，有时需要阻止元素的默认行为。在事件处理函数中，可以使用return false阻止元素的默认行为，也可以使用preventDefault()方法实现。

4. 事件委托

在日常生活中，为了提升快递的派送效率，快递员会把快递存放到相关代收机构，然后让客户自行领取，这种处理方式称为委托。DOM中的事件委托是指当事件被触发时，将需要做的事委托给父元素处理。

# 7.3.2	事件对象的常用属性和方法

4. 事件委托

事件委托（或称为事件代理）的原理是将子节点对应的事件注册给父节点，并通过事件冒泡的原理影响到每个子节点。事件委托的优势如下。

当一个父节点中所有子节点的事件处理函数相同时，不必为每个子节点注册事件。
当父节点中的子节点需要动态地增加时，不必为新增加的子节点注册事件。

虚拟键码27：代表“Esc”键。
虚拟键码32：代表“Space”键。即空格键。
虚拟键码37~40：代表方向键左（）、上（）、右（）、下（）。

# 掌握元素偏移量操作，能够使用offset系列属性进行元素偏移量操作

7.6.1	元素偏移量操作

先定一个小目标！

# 元素偏移量（offset）是指页面中元素相对于文档区域左上角的位置和大小。在实际开发中，通过offset系列属性可以获取元素的位置、大小等。offset系列属性如下表所示。

7.6.1	元素偏移量操作

| 属性 | 说明 |
|---|---|
| offsetParent | 向上层查找最近的设置定位的父元素，或最近的table、td、th、body元素，返回找到的元素 |
| offsetLeft | 获取元素相对其offsetParent元素左边界的偏移量 |
| offsetTop | 获取元素相对其offsetParent元素上边界的偏移量 |
| offsetWidth | 获取元素（包括padding、border和内容区域）宽度 |
| offsetHeight | 获取元素（包括padding、border和内容区域）高度 |

# offset系列属性都是只读的，获取的结果为数字型像素值。定位是指元素的CSS样式中设置了position定位。使用offsetParent属性查找父元素时，如果父元素没有设置定位，则继续向上层查找祖先元素。

若元素的display设置为none，则offsetParent属性会返回null；若元素的position被设置为fixed，则offsetParent属性不会返回null，而是会指向最近的固定定位的祖先元素，如果不存在祖先元素，就会指向根元素。

# offset系列属性与style属性的区别

多学一招

offset系列属性和style属性都可以获得元素样式的属性和位置，但是二者具有一定的区别，具体如下表所示。

7.6.1	元素偏移量操作

| offset系列属性 | style属性 |
|---|---|
| offset系列属性可以得到任意样式表中样式值 | style属性只能得到行内样式表中的样式值 |
| offset系列属性获得的数值不带有单位 | style.width获得的是带有单位的字符串 |
| offsetWidth包含padding、border、width的值 | style.width获得的是不包含padding、border的值 |
| offsetWidth是只读属性，只能获取不能赋值 | style.width是可读写属性，可以获取也可以赋值 |

# 多学一招

需要注意的是，offset系列属性是只读属性，只能获取元素的宽度，而style属性可以通过赋值修改元素样式。当需要获取元素的大小或位置时，使用offset系列属性更合适；当需要给元素更改值时，使用style属性更合适。
